Episode 2Last time: We need a common stick.
🏛️📏

In 1799 France locked a platinum bar in a vault and said: this is the metre.

Today the metre is not a stick at all. It is defined by how far light travels in a tiny slice of a second.

Why would scientists throw away a perfectly good metal bar?

Tell the story: after the French Revolution, France wanted one measure for everyone. A platinum bar was made in 1799. But metal expands when it gets hot, and bars can be damaged. In 1983 the metre was redefined using the speed of light (299,792,458 m/s), which is the same everywhere in the universe. Ask: “What do you think is more reliable — a bar in a vault or a property of nature?”

2 · System of units · Conversion of units

The length stays the same — only the number changes

n u = constant → x y = k → y = kx

n × u is always the same. So a bigger unit gives a smaller number, and a smaller unit gives a bigger number.

Size of the unit u (kilometres)
5 km = 5000 m   (smaller unit → bigger number)

The same length of 5 km is 5 in km but 5000 in m. Slide the unit size — the point rides a rectangular hyperbola because n × u never changes.

"If I change the unit from metre to centimetre, does the length become 100 times longer?" (No — the number is 100× larger, the length is unchanged.)

Students write n₁u₁ = n₂u₂ correctly but then multiply instead of divide. Always ask: is the new unit bigger or smaller?

Speed in km/h
Why? 1 km/h = 1000 m ÷ 3600 s = 5/18 m/s  ·  e.g. 36 km/h = 10 m/s

3 · Significant figures · Zeros

Only zeros are confusing

Non-zero digits always count. For zeros, ask: where is the zero?

Zero in the middle

Counts ✔

It sits between two real digits — you really measured it. 3 digits count.

Zeros at the front

Do not count ✘

They only show where the decimal point is. 0.0062 m = 6.2 mm — same 2 digits.

Zeros at the end

Count — if there is a decimal point ✔

Writing 2.500 says “I measured to 3 decimals”. All 4 digits count.

CarefulFor 4700 (no decimal point) the end zeros do not count → 2 digits. Write 4700. (or 4.700 × 10³) when you want all 4 digits to count.

3 · Significant figures · Rules for rounding off

Look at the digit you are dropping

Rule 1

Dropped digit is more than 5 → round the last kept digit up.

2.746 → 2.75
Rule 2

Dropped digit is less than 5 → leave the last kept digit as it is.

1.743 → 1.74
Rule 3

Dropped digit is exactly 5: make the last kept digit even.
A) it is odd → go up  B) it is even → stay.

2.735 → 2.74  |  2.745 → 2.74
round to 3 s.f.

Always ask: which digit is being dropped? Then decide: more than 5 up, less than 5 stay, exactly 5 → make the kept digit even (round-half-even, the rule in these notes).

"Round 2.735 and 2.745 to three figures — why do they end up with the same last digit?" (both become even: 2.74)

If 5 is followed by any non-zero digit (e.g. 2.7351), it counts as 'greater than 5' and rounds up.

3 · Significant figures · Rules for arithmetic operations

Add: count decimals. Multiply: count digits.

Adding or subtractingCount decimal places

Your answer gets as many decimal places as the number that has the fewest.

436.32 + 227.2 + 0.301 = 663.821 → 663.8

Multiplying or dividingCount significant figures

Your answer gets as many significant figures as the number that has the fewest.

4.237 ÷ 2.51 = 1.6880… → 1.69
Do not mix them up: + and − → decimal places. × and ÷ → significant figures.

4 · Dimensions

Dimension = the “type” of a quantity

5 m, 5 km and 5 cm are all lengths — same type. 5 s is a time — a different type.

📏

Type: length[ L ]

metre, km, cm, inch, foot — all are L.

⚖️

Type: mass[ M ]

kg, gram, quintal — all are M.

⏱️

Type: time[ T ]

second, minute, hour — all are T.

Mixing types

Speed = length ÷ time → type [ L T⁻¹ ]

Mixing types

Area = length × length → type [ L² ]

RememberThe dimensional formula tells which base types a quantity is made of — and with what powers.

Dimensions are not units. Kilometre and centimetre are different units but the same dimension. Dimension answers: "what kind of thing is it?"

"Is an hour the same dimension as a second?" (Yes — both are time, [T].)

5 · Applications of dimensional analysis · 3

The principle of homogeneity

Principle
A physical equation is dimensionally correct only if the dimensions of every term on both sides are the same.

Rule AAdd, subtract or equate → same dimensions

You cannot add a length to a time.

Rule BExponents & functions → dimensionless argument

In ex, sin x, log x, the quantity x must be dimensionless.

Worked exampleNEET
V = V₀ e−kt²
1The exponent kt² must be dimensionless
2[k][t²] = [M⁰L⁰T⁰]
3[k] = 1 / T² = T⁻²
Answer: [k] = [T⁻²]

5 · Applications of dimensional analysis · 5

Four limitations

1

It cannot give the dimensionless constants

½ in ½mv², 2π in T = 2π√(l/g) — invisible to dimensions.

2

It cannot derive trigonometric, exponential or log relations

Their arguments are dimensionless, so nothing can be equated.

3

It fails if a quantity depends on more than three variables (in mechanics)

Only M, L, T are available to equate — we cannot solve for four or more powers.

4

It cannot tell scalar from vector — or correct from true

Dimensionally right ≠ physically right: KE = mv² passes the check but is wrong.

Reveal one limitation at a time and give one example for each.

6 · Errors

Error is not a mistake

Five students measure the same desk with the same ruler.

🧑‍🎓120.2 cm
👩‍🎓120.5 cm
🧑‍🎓120.1 cm
👩‍🎓120.4 cm
🧑‍🎓120.3 cm
Nobody did anything wrong. No measurement is perfect. The small difference between a measured value and the true value is called error.
Reason 1

The ruler has limits — we cannot read finer than its smallest mark.

Reason 2

Our eyes and hands are not perfect.

Reason 3

Small changes in the room — temperature, vibrations.

GoalWe cannot remove error — but we can estimate how big it is and report it honestly.

Stress that error ≠ blunder. A blunder is a mistake (reading the wrong scale). Error is the unavoidable uncertainty.

"Which student is right?" (All of them — within the ruler's precision.)

6 · Error analysis · Live

Every measurement has error

Measure the same rod again and again — the readings scatter around the true value.

Press "Take a reading" several times. Notice the mean settles near the true value (gold line) while individual readings scatter — that scatter is the random error. Slide the systematic error to shift every reading the same way.

"Can taking more readings remove a systematic error?" (No — it shifts the mean away from the true value.)

6 · Errors · Two kinds

Two kinds of error: always same way or both ways

⚖️

Systematic errorAlways pushes the same way

A weighing machine shows 2 kg even when nothing is on it. Every reading is 2 kg too high.

Cause: faulty instrument, zero error, wrong method.
Fix: correct it (subtract the 2 kg).

⏱️

Random errorSometimes more, sometimes less

You press the stopwatch a little early or a little late each time. Readings scatter both sides of the true value.

Cause: unpredictable small things.
Fix: take many readings and use the average.

NextAveraging many readings shrinks random error — it can never remove systematic error.

Systematic = shifts all readings in one direction (bias). Random = scatter. Averaging reduces random error but never removes systematic error.

6 · Error analysis · Propagation

Errors add — but different things add

Sum or differenceAbsolute errors add

Z = A ± B  ⇒  ΔZ = ΔA + ΔB

Product or quotientFractional errors add

Z = A × B or A / B  ⇒  ΔZ/Z = ΔA/A + ΔB/B

Trap: the error in a difference is the sum of errors — never subtract them.
A±
B±

Run A = 10.5 ± 0.1 and B = 26.8 ± 0.1 for each operation. Sum and difference share the same ΔZ = 0.2.

A − B has absolute error ΔA + ΔB = 0.2 — the same as A + B. Subtracting two close numbers makes the fractional error explode.

6 · Errors · Combining

Why do errors add?

Two rods: A = 10.0 ± 0.1 cm and B = 5.0 ± 0.1 cm. Join them end to end.

Try the worst cases. For A + B, both rods could be too long (15.2) or both too short (14.8). For A − B, A too long and B too short gives 5.2; the reverse gives 4.8. Either way the spread is ± 0.2.

Errors never cancel in the worst case — so even for subtraction, we ADD the errors.

The vernier trick: slightly smaller marks

A ruler reads only to 1 mm. A vernier reads to 0.1 mm. How?

📏

Fixed ruler with marks every 1 mm.

🔬

Vernier scale10 divisions = 9 mm

So 1 vernier division = 0.9 mm — a little shorter than 1 mm.

Each vernier mark falls 0.1 mm behind the main-scale mark: 1 − 0.9 = 0.1 mm.

Least count = 1 MSD − 1 VSD

If a VSD = b MSDLC = (a − b)/a × 1 MSD

Standard vernier: 10 VSD = 9 MSD and 1 MSD = 1 mm → LC = 1/10 mm = 0.1 mm = 0.01 cm.

7 · Least count & instruments · Vernier calipers

Zero error: subtract if positive, add if negative

Jaws closed — vernier zero is…
Observed reading (cm)

Close the jaws. If the vernier zero is to the right of the main zero, the n-th line coincides and the error is +n × LC. If it is to the left, the n-th line coincides and the error is −(10 − n) × LC.

Correct reading = observed reading − zero error (zero error carries its sign).
